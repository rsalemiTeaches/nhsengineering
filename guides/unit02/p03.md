In Project 02 you hand-typed a bouncing square, line by line, so you'd know exactly what that kind of program looks like. This project is different: you will not write a single line of code yourself. Instead, you will describe what you want in plain English, hand that description to Ollama — a coding AI running on this computer — and let it write the program for you.

# A new way of building

Starting now, the rule for this class changes. You do not have to read the code Ollama writes, and you are not expected to understand it line by line. 

What you *are* responsible for is the two jobs a human still has to do: writing a clear description of what the program should do — called a **prompt** — and checking that the program the AI built actually does what you asked. If it doesn't, that's a signal to try again, not a bug you're expected to find and fix by reading the code.

For this project, the prompt is written for you. Starting next project, you'll write your own.

# Exercise 1: Prompt Ollama for a Bouncing Circle

## Step 1: Make a folder for this project

```
cd $HOME
cd swdev
mkdir proj03
cd proj03
```

## Step 2: Open Ollama and give it the prompt

Open the **Ollama** app. Check that the model selector at the bottom of the window says `qwen2.5-coder:7b` — that's the model that writes code.
![[CleanShot 2026-08-19 at 11.36.31.png]]

Type the following into the message box (where it says "Send a message"), exactly as written, and press Return:

```
Write a Python program using pygame. Open a 500 by 400 pixel window with a
light gray background. Draw a circle with a 60-pixel radius that starts in
the middle of the window and moves in a straight line at an angle. When the circle touches any edge of the window, make it bounce back in the other 
direction and change to a new random color. Run the animation at 60 frames per
second, and keep the window open until the user closes it.
```

Ollama will write back an explanation and a block of Python code.
![[CleanShot 2026-08-19 at 11.42.54 2.png]]
## Step 3: Copy the code

Ollama sometimes shows more than one block — a short one labeled **bash**
for installing packages, and the real program labeled **python**. Skip the
bash block; you don't need it, since Step 5 handles installing pygame.
Find the block labeled **python** and click the **Copy** button on that
one. This copies only the code — not Ollama's explanation around it.

## Step 4: Put the code in a file

```
touch circle.py
cot circle.py
```

Paste the code you copied into the CotEditor window, and save it with **Command-S**. Leave the window open — you will be back.

## Step 5: Tell uv this program needs pygame

```
uv add --script circle.py pygame
```

## Step 6: Run it

```
uv run circle.py
```

## Step 7: If it crashes

Sometimes, instead of a window, you'll get a wall of red text in Terminal ending in a line like `AttributeError: ...` or `SyntaxError: ...`. That's called a **crash**, and it means the program never ran at all. It's a normal part of working with an AI that writes code — it doesn't always get every detail right on the first try.

You don't need to figure out what the error means. Just hand it back to the AI:

1. Copy the error text from Terminal — the last several lines, ending with the line that starts with the error's name, are enough.
2. Go back to Ollama, in the same chat.
3. Paste the error and add a sentence like: "This crashed with the error above. Please fix it."
4. Ollama will send back corrected code. Copy the new **python** block, click into the CotEditor window, select everything that is there with **Command-A**, paste over it with **Command-V**, and save with **Command-S**.
5. Run it again (Step 6).

If it crashes again, repeat this loop with the new error.

## Step 8: Check it against the prompt

Once it runs without crashing: don't look at the code. Look at the window. Check it against what the prompt actually asked for:

- Does a light gray window open, about 500 by 400 pixels?
- Does a circle appear and move smoothly across the window?
- When it reaches an edge, does it bounce back the other way?
- Does its color change when it bounces?
- Does it keep running until you close the window?

If all five are true, Ollama built what you asked for.

## Step 9: If it runs but doesn't match

If it doesn't match — say the circle doesn't change color, or it stops at the edge instead of bouncing — go back to Ollama and send the same prompt again. Asking again is a normal part of the process, not a sign you did something wrong.

```
git commit -m "AI-generated bouncing circle"
```
