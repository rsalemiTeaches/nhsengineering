Later this unit you will describe a program in plain English and let an AI write the code.

First you need your tools. There are four: a terminal, a folder tracked by git, a way to run Python called uv, and a plain text editor.

You set all four up today. Then you never have to think about them again.

# Exercise 1: Set Up Your Tools

## Step 1: Open the Terminal

Press ⌘-Space, type "Terminal", and press Return.

A terminal lets you control the computer by typing commands instead of clicking icons. Everything in this unit happens there.

## Step 2: Put your three apps in the Dock

Terminal's icon is now in the Dock at the bottom of the screen.

**Right-click that icon. Go to Options. Choose Keep in Dock.**

Now do the same for two more apps. Open each one with ⌘-Space, then right-click its Dock icon and choose Keep in Dock:

- **Ollama**, the AI that will write your code
- **CotEditor**, the editor you will type in

Terminal, Ollama and CotEditor should all be in the Dock now. You only have to do this once.

## Step 3: Make a home for your work

Type this and press Return:

```
mkdir swdev
```

`mkdir` means "make directory." You just made a folder named `swdev`, short for "software development."

Every project you build this term goes inside it.

Now move into the folder:

```
cd swdev
```

`cd` means "change directory." Any command you type next happens inside `swdev`.

## Step 4: Turn your work folder into a git repository

Type this:

```
git init
```

Git saves snapshots of your work as you go. A snapshot is called a **commit**.

Once you commit something, you can always get back to that exact version. That is true even if you break everything after it.

Nothing is saved yet. `git init` only tells git to start watching this folder.

## Step 5: Check that uv is there

Type this:

```
uv --version
```

You should see a version number. If you see `command not found`, stop and tell your teacher. Nothing else in this unit works until that does.

uv runs Python for you. It also manages **packages** — code someone else already wrote that your program can use.

Later you will use a package called `pygame` to build your game. You tell uv what you need and it does the rest.

## Step 6: Make a folder for this project

Every project gets its own folder inside `swdev`.

```
mkdir proj01
cd proj01
```

## Step 7: Write your first program

Make an empty file:

```
touch hello.py
```

`touch` makes a file with nothing in it.

Now open it in the editor:

```
cot hello.py
```

`cot` is CotEditor's command. It opens the file in a window next to your Terminal. Leave both open — you will use both at once all term.

A code editor is not like Word or Pages. It saves plain text with no hidden formatting. That is what a program file has to be.

Type exactly this:

```
print("Hello, world!")
```

Save it with **Command-S**. Leave the window open and click back to Terminal.

## Step 8: Run it

```
uv run hello.py
```

You should see:

```
Hello, world!
```

`hello.py` needs no packages, so uv just found a Python and ran the file.

Next project you will see uv install a package first. That is the same job on a program that needs more than plain Python.

## Step 9: Save your work with git

Move back up to `swdev`:

```
cd ..
```

Then take the snapshot:

```
git add .
git commit -m "My first program"
```

`git add .` tells git which files to include. The `.` means all of them.

`git commit` takes the snapshot and saves your message with it. Later you can look back and see what you built and when.

Every project this term ends with a commit like this one.
