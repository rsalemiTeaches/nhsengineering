Later in this unit, you will describe programs in plain English and have an AI write the code for you. Before that, you need the tools every project this term depends on: a terminal, a project folder tracked with git, a way to run Python called uv, and a plain text editor. This project sets all four up, once, so you never have to think about them again.

# Exercise 1: Set Up Your Tools

## Step 1: Open the Terminal

A terminal is a way to control your computer by typing commands instead of clicking icons. Everything in this unit happens there.

Press ⌘-Space, type "Terminal", and press Return.

## Step 2: Make a home for your work

Type this and press Return:

```
mkdir swdev
```

`mkdir` means "make directory" — it creates a folder. You just created a folder named `swdev`, short for "software development." Every project you build this term will live inside it.

Now move into that folder:

```
cd swdev
```

`cd` means "change directory." Your terminal now treats `swdev` as the folder you are working in, so any command you type next happens there.

## Step 3: Turn your work folder into a git repository

Git is a tool that saves snapshots of your code as you go, called **commits**. Once something is committed, you can always get back to that exact version, even if you break everything after it. 

```
git init
```

This turns `swdev` into a git repository. Nothing is saved yet — `git init` just tells git to start watching this folder for changes.

## Step 4: Install uv

Homebrew is a tool that installs and manages other programs for you. You'll use it just this once, to install uv.

uv is a tool that installs Python itself and manages **packages** — code someone else already wrote that your program can use instead of you writing it from scratch. Later this unit, you'll use a package named `pygame` to build your game. Instead of installing Python and packages by hand, you tell uv what you need and it handles the rest, one project at a time.

```
brew install uv
```

Homebrew installs uv into a folder already on your terminal's search path, so there is nothing else to set up — no need to close and reopen the terminal.

Check that it worked:

```
uv --version
```

If you see a version number, uv is installed.

## Step 5: Make a folder for this project

Every project gets its own folder inside `swdev`.

```
mkdir proj01
cd proj01
```

## Step 6: Write your first program

A code editor is different from Word or Pages — it saves plain text with no hidden formatting, which is exactly what a program file needs to be. You will write this first program by hand, so you know what a real Python file looks like before you start asking an AI to write them for you.

Open the editor:

```
pico hello.py
```

Type exactly this:

```
print("Hello, world!")
```

Now you will save the file and exit: 
- to save press **Control-O** for *output file*, then **Return** to confirm the filename, 
- to exit press **Control-X** to leave the editor.

## Step 7: Run it

```
uv run hello.py
```

You should see:

```
Hello, world!
```

`hello.py` doesn't need any packages, so uv just finds a Python interpreter and runs the file directly. Starting next project, you will see uv install a package before it runs your code — that is uv doing the same job on a program that needs more than plain Python.

## Step 8: Save your work with git

Move back up to your `swdev` folder:

```
cd ..
```

Stage and commit your work:

```
git add .
git commit -m "My first program"
```

`git add .` tells git which changed files to include in the next snapshot — in this case, everything. `git commit` takes that snapshot permanently and records the message you gave it, so later you can look back and see what you built and when. Every project this term ends with a commit like this one.
