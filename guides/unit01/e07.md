This project uses all the techniques you learned in previous projects to create a fun synthesizer. Your job is to create a synthesizer and play a song for Mr. Salemi.

# A synthesizer example

This obnoxious example makes a siren sound by changing the frequency as it runs.

## The hardware

The Arduino tone() function sends pulses of electricity to a pin to create a tone in a speaker. You pass the tone() function the frequency of the tone so that you can make all the notes in the scale.

Here is a simple tone() example from the activity.

# Create a synthesizer

Your job is to create a synthesizer with a button and a rheostat. The button turns the sound on and off, and the rheostat controls the frequency.

## The hardware

You can start with the starter design (below) or add these parts to the example above:

## The software

The code reads the voltage from the rheostat and uses it to set the frequency for the speaker. The synthesizer only makes sound when the user pushes the button.

We use the analogRead() function to read the volageWe use the digitalRead() function to read the button.We use the noTone() function to turn off the sound when the user stops pushing the button.We use the tone() function make the sound at the frequency we got from the rheostat.
