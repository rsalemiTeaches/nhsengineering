Follow these steps to set up your online coding environment. This setup ensures that the code you write in the Tinkercad simulator works perfectly on the physical hardware on your desk.

### Simulate the LCD in TinkerCad

### Import the LCD Library

Download the **LiquidCrystal_I2C.zip** file provided by your instructor.

In the Arduino Cloud sidebar, click on **Libraries**.

Click the **Import** button (the icon with the upward arrow).

Select the LiquidCrystal_I2C.zip file you just downloaded.

Wait for the confirmation message: "Library imported successfully."

### Create the Hardware Check Sketch

Go to **Editor** in the sidebar.

Click **Create New Sketch** and name it LCD_Hardware_Check.

Delete all default code in the window and paste the following:

```
#include <LiquidCrystal_I2C.h>
// Standard setup for our 16x2 Classroom LCDs
// Address: 0x27, Columns: 16, Rows: 2
LiquidCrystal_I2C lcd(0x27, 16, 2);
void setup() {
  Serial.begin(9600);
  // Initialize the LCD
  lcd.init();
  lcd.backlight();
  // Print verification message
  lcd.setCursor(0, 0);
  lcd.print("HARDWARE PASS!");
  lcd.setCursor(0, 1);
  lcd.print("Address: 0x27");
  Serial.println("LCD Initialized Successfully");
}
void loop() {
  // Blink the backlight to prove the board is active
  lcd.backlight();
  delay(1000);
  lcd.noBacklight();
  delay(1000);
}
```

### 4. Connect and Upload

Plug your Arduino Uno into your computer's USB port.

Select **Arduino Uno** from the device dropdown menu at the top.

Click the **Upload (Right Arrow)** icon.

### 5. Troubleshooting the "Blank Screen"

If the upload is successful but you do not see any text:

Look at the back of your LCD screen.

Locate the **blue square potentiometer** (the "contrast knob").

Use a small screwdriver to gently turn the white dial inside the blue square until the letters appear clearly.
