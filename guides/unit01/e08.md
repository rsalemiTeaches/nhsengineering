In this project, we're going to get an LCD display working with our Arduino Uno and have it display a "Hello, world" message.  We will follow these steps:

- Check to see if we have the `LiquidCrystal_I2C` library installed
- Install the `LiquidCrystal_I2C` library if we need it
- Connect the LCD display to the Arduino in TinkerCad
- Copy the LCD HelloWorld example program to TinkerCad
- Run the program
- Do it all again in real life

# Check the `LiquidCrystal_I2C` library
We check for the `LiquidCrystal_I2C` library by seeing if we have example programs installed in our IDE:
![[e08_01.png|421]]

If you can find the `LiquidCrystal_I2C` library under `File -> Examples -> LiquidCrystal_I2C` then you have the library installed.
# Simulate the LCD in TinkerCad
If you don't have the library installed, then get the `LiquidCrystal_I2C.zip` file from Mr. Salemi and install it in your Arduino IDE.  You use the `Sketch -> Include Library -> Add .ZIP Library` menu item to install the library from the `.zip` file.

![[e08_02.png|435]]
Select the zip file
![[e08_03.png|432]]

# Connect the LCD to the Arduino in TinkerCad
![[e08_04.png|550]]

Connect the Arduino to the LCD with four wires:

- VCC on the LCD connects to 5V
- GND on the LCD connects to GND
- SDA on the LCD connects to A4
- SCL on the LCD connects to A5
# Copy the HelloWorld example to TinkerCad
Select `File -> Examples -> LiquidCrystal_I2C -> HelloWorld` in the IDE.  This opens the HelloWorld program:
![[e08_05.png|437]]

Copy the program to TinkerCad

# Do the same thing in real life
Connect your real Arduino Uno to the real LCD Display and use the Arduino IDE to run the same program.
# Troubleshooting a blank screen

If the program simulates but you don't see the message in real life:

## Check the wiring

- Make sure the four wires are securely connected to the right spots.
- Make sure your Arduino is plugged into the computer for power.

## Check the contrast

- Look at the back of your LCD screen.
- Locate the **blue square potentiometer** (the "contrast knob").
- Use a small screwdriver to gently turn the white dial inside the blue square until the letters appear clearly.
