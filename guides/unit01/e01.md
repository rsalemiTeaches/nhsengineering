In this project, we’ll wire an LED so it lights up. We will simulate the circuit, then build it in real life.

**There is no code in this project.** You are only wiring a circuit — the LED lights up on its own once it's connected correctly, with no sketch loaded.

# How a breadboard is wired

The holes aren't as separate as they look. Click any hole in Tinkercad and it highlights every other hole that's electrically connected to it — try it before you wire anything. There are two different kinds of connection on the board.

![[e01_09.png]]

Clicking a hole in the f-j block highlights the other four holes in that same column, because that column of 5 is one connected group. The a-e block works the same way, as its own separate group — each column is its own group, not shared with the next column over.

![[e01_10.png]]

The rows marked + and – are power rails, and they work differently: clicking one hole highlights the *entire* rail, all the way across the board. A rail is one connection end to end, not split into small groups like the rest of the board.

When you make a circuit, connect 5V to the top row with the red + and the GND to the bottom row with the blue -. Then it is easy to connect the other elements between the power and the ground.  It's also easier to debug if all the wiring goes in the same direction.

# Real-life circuit

Get the following parts and build the circuit so that it looks like the simulated one.

**LEDs only work one way around.** In the simulator, the LED's bent leg marks positive. On a real LED, that's the longer leg — match it to the same side as the simulated circuit before you power it on.
