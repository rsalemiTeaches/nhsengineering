In this project, we will make an LED on a breadboard blink along with the LED on the Arduino board.

There is no new code in this project. You wrote the code in [[e00|Project 00]], where you changed the blink sketch in the IDE and watched the built-in LED. This time the job is the wiring: put an LED on the breadboard and make it blink along with the one on the board.

# Arduino pin 13

On an Arduino UNO, the LED_BUILTIN pin number (which you see used in the code) is pin 13. We will use pin 13 to make an LED blink on the breadboard.

Load the plain **Blink** example again for this project, so the LED blinks steadily instead of spelling S-O-S.
