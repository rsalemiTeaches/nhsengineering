## Step 2: Examine the Arduino sketch and modify it

The Arduino world calls a program a ***“sketch.”*** You write sketches in the IDE and load them into the Arduino board. A sketch has two function calls ***setup()*** and ***loop()***:

We write Arduino code in a language named C++. The command functions are red, so pinMode(), digitalWrite(), and delay() are all command functions. When we use functions, we say that we ***“call”*** the function.

## Calling a function

We call a function by typing its name on the line of code and then following the name with parenthesis.

Sometimes, functions need information to run properly. We provide the information by putting it between the parenthesis. Data passed between the parentheses is called an argument. You can have more than one argument when you call a function.

For example, the delay() function needs to know how many milliseconds (1/1000 of a second) you want to delay, so you pass it one argument.

```
delay(1000);
```

If you pass more than one argument to a function, the arguments must be in the correct order. For example, the pinmode() function above has two arguments. The first is the pin, and the second is whether that pin is an input or an output.

```
pinMode(LED_BUILTIN, OUTPUT);
```

The first argument identifies the LED_BUILTIN pin. The second argument says that this is an output pin.

## The setup() and loop() functions

The Arduino board calls two functions named setup() and loop():

setup()—The Arduino calls this function first and calls it only once. You use this function to set things up. In this case, the code on line 28 calls pinMode() to designate the pin named LED_BUILTIN as an OUTPUT. The pinMode() function tells the Arduino that we will write values to that pin to make the built-in LED turn on or off.

loop()—The Arduino calls the loop() function over and over as quickly as possible. If you want to slow things down, you need to use the delay() function. Pass delay() the number of *milliseconds* to delay*.* Since a millisecond is a thousandth of a second, 1000 milliseconds is a second. The light turns on for a second and turns off for a second.The digitalWrite() function writes a value to a pin. The function takes two arguments, the pin number and the value to write. We usually pass this function a pin number, but in this case, we pass *LED_BUILTIN*. Writing HIGH to the LED_BUILTIN pin turns the light on. Writing LOW to the LED_BUILTIN turns the light off.

Morse code is a system of communicating when you can only blink a light. The code uses long blinks and short blinks to indicate different letters. Flex by having the Arduino blink the S-O-S Morse Code.

The Morse Code for **S** is short-short-short

The Morse code for **O** is long-long-long

The Morse Code for **S-O-S** is:

short-short-short-long-long-long-short-short-short
